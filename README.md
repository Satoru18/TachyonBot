# TachyonBot

Bot de Discord en Python para reproducir música y responder comandos básicos.

## Requisitos

- Python 3.9+
- discord.py

## Instalación

1. Clona este repositorio.
2. Instala las dependencias:
   ```bash
   pip install discord.py
   ```
3. Configura tu token en el archivo `settings.py`.

## Uso

Ejecuta el bot con:

```bash
python main.py
```
